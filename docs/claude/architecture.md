# Architettura

- `main.go`: app Wails v3, finestra frameless 1240x820, assets embed `frontend/dist`.
- `service.go`: unico servizio esposto al frontend (bindings in `frontend/bindings`, generati). Metodi: Installs, Profile, AddFolder/RemoveFolder, CachedNames/ResolveNames, ClientStatus, Apply, Backups, Restore, DeleteBackup, OpenBackupsFolder, Preview (sola lettura, vedi sotto). Apply/Restore tornano `Result{ok, code}` (codici: client_running, bad_request, bad_backup, io), mai eccezioni per casi attesi.
- `internal/eve`: scoperta radici (Windows/macOS/Proton + `libraryfolders.vdf` + cartelle manuali), server -> `settings_*` -> `core_char_<digits>.dat`/`core_user_<digits>.dat`; rilevamento client (`/proc/*/cmdline` con `exefile.exe`, tasklist su Windows, ps su macOS).
- `internal/esi`: POST `universe/names` a lotti (404 sul lotto => split binario), cache `names.json`.
- `internal/backup`: zip + `manifest.json` in `<UserConfigDir>/capsuleers.settings/backups`, apply, restore (valida che ogni percorso stia nella `profileDir` del manifest e abbia nome `core_*_<n>.dat`), tiene gli ultimi 20.
- `internal/config`: `config.json` con le cartelle aggiunte a mano.
- Frontend: Vue 3 + TS; stato globale in `src/store.ts` (reactive), 5 viste in `src/views/` (Profiles, Characters, Preview, Review, Backups), stringhe in `src/i18n.ts`.
- `core_user`: opzione disabilitata nel prototipo; la mappatura account arriva dopo.
- Frameless su Linux/Wayland: GTK3 con `decorated=FALSE` non annuncia CSD e KWin aggiunge la sua barra (doppia barra). `frameless_gtk3.go` (cgo, tag gtk3) crea la finestra `Hidden`, a runtime pronto imposta un titlebar GTK vuoto e nascosto (= CSD annunciato) con ombra/bordo/raggio azzerati e poi `Show()`; su X11 non fa nulla. Verificato su KDE 6.7 Wayland: frame == client. Drag/min/max/close sono quelli Wails invariati (click reali non iniettati nel test).
- Rilevamento client: conta solo processi con un argomento il cui nome file e' `exefile.exe` (non una semplice menzione in cmdline: shell, grep).

## Preview (sola lettura)
- `internal/marshal`: decoder puro Go, SOLO lettura, del formato CCP blue.marshal (opcodes da reverence `src/blue/marshal.c`). Mai un encoder nell'app: l'app copia file interi. Encoder di test in `internal/marshal/marshaltest` (fixture sintetiche; mai file reali nel repo).
- Formato: byte 0x7E, uint32 N slot condivisi, oggetti, poi tabella di N uint32 in coda. L'i-esimo oggetto con flag 0x40 (nell'ordine di incontro, contenitori contati all'apertura) occupa lo slot `tabella[i]-1`; REF n -> slot n-1. Stringhe/chiavi sono BUFFER (0x13); dict contati scrivono prima il valore poi la chiave; newobj/reduce = testa, elementi, MARK (0x2d), coppie chiave/valore, MARK. DBROW/BLUE/PICKLER non supportati (errore); STRINGR (tabella stringhe del client) diventa `<strtab:N>`; checksum 0x1c non verificato.
- Limiti: input 16 MB, profondita' 128, decoder iterativo, ogni lunghezza verificata contro i byte rimasti, `Decode` non va in panic (recover -> `ErrFormat`). `FuzzDecode` (`go test ./internal/marshal -fuzz FuzzDecode`). Corpus reale opzionale: `CAPSULEERS_CORPUS=<dir> go test ./internal/marshal ./internal/charsettings -run RealCorpus`.
- `internal/charsettings`: ogni valore di impostazione e' `(timestamp FILETIME, valore)`, in gruppi di primo livello (`windows`, `ui`, ...). Finestre: `windows/windowSizesAndPositions_<n>` = dict id -> `(left, top, width, height, schermoW, schermoH)`; ogni finestra ha le dimensioni dello schermo al salvataggio (UI scale 90% => 2133x1200, file misti normali). Il significato di `<n>` non e' documentato (nel corpus solo `_1`): si usa l'entry col timestamp piu' recente. Stato da `openWindows` (solo le aperte), `lockedWindows`, `collapsedWindows`, `compactWindows`, `minimizedWindows`; gruppi da `stacksWindows` (id -> stack padre, nil = libera), ordine tab da `preferredIdxInStack3`. Si mostrano solo le finestre di primo livello aperte; dialoghi transitori e stack numerici senza tab sono esclusi (`isTransient`, `numericRe`). Canali chat: `ui/chatchannels` (lista di `(suffisso, chiave, nome)`) piu' `chatchannel_*` aperti.
- Diff per id finestra: stesso rettangolo (tolleranza 0.4% dello schermo se gli schermi differiscono) = same, diverso = move, solo sorgente = add, solo destinazione = remove. Scala UI/schermo da `core_public__.yaml` (`LoadDisplay`, scanner a righe, no YAML). Etichette EN/IT in `labels.go`, id ignoti mostrati grezzi.
- `Service.Preview(profileDir, sourceId, targetId, lang)` torna `PreviewResult` (mai eccezioni): per lato `error` `""|missing|unreadable`; un file non leggibile dà lo stato vuoto "can't read this file" e Apply non ne dipende. Vista: `PreviewView.vue`, raggiungibile da Characters e dalla rail.
